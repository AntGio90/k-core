# Professional Network Analyzer Plugin - Quick Installation Guide

## 🚀 Quick Setup (5 minutes)

### Step 1: Extract Files
Extract this ZIP file to your Cheshire Cat plugins directory:
```
/path/to/cheshire-cat/plugins/professional_network_analyzer/
```

### Step 2: Required Files (Already Included)
✅ professional_network_analyzer.py  (Main plugin file)
✅ plugin.json                      (Plugin configuration)
✅ README.md                        (Full documentation)

### Step 3: Restart Cheshire Cat
```bash
# Restart your Cheshire Cat instance
docker-compose restart  # or however you run Cheshire Cat
```

### Step 4: Activate Plugin
1. Go to Admin Panel: http://localhost:1865/admin
2. Navigate to "Plugins" section
3. Find "Professional Network Analyzer" 
4. Click "Activate" button

### Step 5: Test Installation
Open the chat interface and try:
```
Analizza il profilo di Mario Rossi
```

You should see a detailed professional profile analysis.

## 🎯 What This Plugin Does

This plugin implements professional network analysis for Cheshire Cat AI:

- **Profile Analysis**: Identify and analyze professional profiles
- **Network Exploration**: Map professional relationships and connections  
- **Company Mapping**: Visualize organizational structures
- **Skill Networks**: Analyze competency distributions
- **Work Context**: Identify projects, teams, and professional environments
